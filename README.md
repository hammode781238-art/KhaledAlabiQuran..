# تطبيق ختمة الشيخ خالد العلبي

تطبيق Android احترافي بواجهة عربية RTL للاستماع إلى أجزاء الختمة المرتلة بصوت الحافظ الجامع الشيخ محمد خالد العلبي.

## المحتوى
- 30 جزءًا.
- كل جزء مرتبط بفيديو YouTube الذي زوّدني به المستخدم.
- بحث سريع عن الأجزاء.
- تصميم Material 3 حديث.
- دعم RTL واللغة العربية.
- زر استماع يفتح التلاوة في YouTube أو المتصفح.
- GitHub Actions لبناء APK تلقائيًا.

## البناء على GitHub
1. ارفع هذا المشروع إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل Workflow باسم **Build Android APK**.
4. بعد نجاح البناء ستجد ملف APK في Artifacts باسم `KhaledAlabiQuran-debug-apk`.

> ملاحظة: التطبيق لا ينسخ أو يستضيف ملفات الفيديو/الصوت من YouTube؛ بل يفتح الروابط الأصلية. تأكد من امتلاكك الحقوق والأذونات اللازمة لأي محتوى تريد تضمينه أو إعادة توزيعه.

## روابط الأجزاء
الروابط موجودة مباشرة داخل `MainActivity.kt` ويمكن استبدالها لاحقًا بمصدر صوتي مرخّص أو API خاص بك.
